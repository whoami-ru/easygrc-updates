# EasyGRC: обновления

Здесь лежит список выпущенных версий EasyGRC и его подпись. Установленная система читает этот список, чтобы показать в колокольчике, что вышла новая версия и что в ней изменилось.

- `stable.json` - версии, даты, описание изменений и контрольные суммы архивов.
- `stable.json.sig` - подпись этого списка. Система проверяет её сама, и если файл изменён, список не принимает.

Самих программ тут нет, и править файлы вручную не нужно.
