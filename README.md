# EasyGRC — канал обновлений

Публичный манифест выпущенных версий EasyGRC. Его читают установленные
системы: колокольчик в шапке показывает новую версию и список изменений, а
агент обновлений на сервере по нему скачивает и ставит обновление.

| Файл | Что это |
|---|---|
| `stable.json` | Выпущенные версии: номер, дата, список изменений, с какой версии проверено обновление, имя, размер и SHA-256 архива поставки |
| `stable.json.sig` | Подпись `stable.json` (Ed25519, base64). Установки проверяют её своим ключом и отвергают манифест, если она не сходится |

Файлы пишет только сценарий выпуска релиза (GitHub Actions) — **не
редактируйте их вручную**: изменённый без подписи манифест установки не
примут. Сами архивы поставки здесь не хранятся.
